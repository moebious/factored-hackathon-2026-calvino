💡 ¿Qué pierdes si NO pagas Dockerfile?

Únicamente ~25 segundos que toma descargar los pesos la primera vez que el contenedor despierte. Pero como Calvino incluye un keep-alive ping periódico en GitHub Actions, el Space permanecerá activo en memoria de forma ininterrumpida.

🎯 La Solución Inteligente para Fine-Tuning

Hacer fine-tuning en un Space (incluso de pago) es mala práctica porque su CPU es lenta. El camino profesional MLOps es: entrenar en Kaggle / Colab (2x NVIDIA T4 gratuitas) en 3 minutos, subir el checkpoint al Model Hub de Hugging Face y consumirlo desde el Space de Gradio.

🚀 Acción Inmediata Recomendada

Crear el Space con Gradio SDK en https://huggingface.co/new-space bajo el nombre calvino-laya. Cero tarjeta de crédito, 16 GB de RAM asegurados y todo listo para montar la API de FastAPI.
